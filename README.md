# Steam Game Analytics Dashboard

An end-to-end data project that fetches Steam game data from the SteamSpy API, 
stores it in PostgreSQL, cleans it with Pandas, and visualizes it through a 
Next.js dashboard deployed on Vercel.

## Stack
- Python, Pandas — data pipeline and cleaning
- PostgreSQL — local database
- Supabase — cloud database
- Next.js, Recharts — frontend dashboard
- Vercel — deployment
